XR Fragments Microformat


This HTML page implements the XR Fragments microformat.
It allows (JML)browsers to derive an experience (or portals) from an webpage/backend without having to implement a full webbrowser.

Currently icosa.gallery (which OpenBrush and OpenBlocks publish to) implements this.

Usecases

  • being able to link directly to icosa.gallery experience via <link url="https://icosa.gallery/2l3k4jk234"/>
  • being able to link directly to an icosa.gallery collection (which renders as Janus Portals) via <link url="https://icosa.gallery/collections/LSc_DPROGR8"/>
